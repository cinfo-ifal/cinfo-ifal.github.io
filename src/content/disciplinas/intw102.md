Introdução às Tecnologias Web oferece uma visão geral dos principais conceitos e ferramentas utilizadas no desenvolvimento de soluções para a web. O curso aborda tecnologias como HTML, CSS e JavaScript, preparando os alunos para a criação de websites e interfaces interativas. Esta disciplina é oferecida na modalidade de ensino a distância (EAD).
