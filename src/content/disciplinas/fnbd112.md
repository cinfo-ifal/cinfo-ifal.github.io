A disciplina de Fundamentos de Banco de Dados é essencial para a criação e manutenção de sistemas de armazenamento de dados. Ao longo das 80 horas, os alunos exploram os princípios básicos de bancos de dados relacionais, além de aprender sobre o uso de SQL para manipulação e consulta de dados.
