A disciplina de Estatística Aplicada oferece aos estudantes de Sistemas de Informação uma visão abrangente sobre o uso de técnicas estatísticas para análise de dados. Durante as 80 horas, são abordados conceitos e ferramentas estatísticas fundamentais para a tomada de decisões informadas com base em dados quantitativos.
